# Group ops — data plan (group seed R2, actors, job allow-list, concurrency)

Source: `areas/portal-ops/data-plan.md` (A-portal-ops, 2026-10-23) with the S1 reconciliations: DM-Y is shared with utr, planner and auth; the windows are the env-plan ones (W-Y-HEALTH, W-Y-MSG, J-Y-JOBS, S-CT-JOBS, S-CT-LOGLEVEL, T-Y-TENANTFORM); TA is the steward's kit actor; STAGE windows are requested by the steward with the user's OK. This group needs no PEP flow, no roster, no pools and no SQL seed.

## 4. Owned names and recipients (hard rules)

- Only the throw-away names `e2e-ops-<tag>` (organisation), `e2e-ops-<tag>-test|-prod` (tenants), `e2e-ops-<tag>.invalid` (domain / host), `e2e-ops-p<tag>` (plugin), `e2e.ops.f<tag>` (master flag), incidents `E2E-OPS-<tag>-*` with one tenant-scoped ignore rule, one recording session, the suite's `99.*` config version.
- On DM-Y only: the ignore flag (X08, restored), the licence re-save (OPS-09), the `general.logs.skip` override (OPS-14 / 22, deleted), one unchanged "Save Tenant" (X19), incidents with the run prefix.
- E-mail domains and api-gw URLs of throw-away tenants use the reserved TLD `.invalid` (RFC 2606).
- SMS only to the pre-filled sms-logger test number, only in X13 part 2, only after OPS-G5.

## 7. Cleanup

OPS-06 removes the throw-away organisation and tenants (leftovers reported, never deleted through test-data endpoints); X08 restores the ignore value; MISC deletes the `general.logs.skip` override, the inert flag, resolves the run incidents and deletes the ignore rule; X19 deletes the plugin; X16 restores the logger level; the steward switches Send Messages OFF. The run summary lists every leftover from `created/*.jsonl`.
