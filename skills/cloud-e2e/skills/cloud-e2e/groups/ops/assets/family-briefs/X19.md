## OPS-19 — Data plugins: create, validate, data table / graph, load more, delete

1. `/ops/data-plugins` "Data Plugins": tag filter and plugin selector load; capture `GET /admin/plugins` and `/admin/plugins/summary`. Shot `01-list.png`.
2. Plugin → "Create new": Name `e2e-ops-p{{RUN_TAG}}`, filter `event.type == 'AUDIT_LOG' && event.tenantId == '{{TENANT}}'`, mapping `event.attributes.get('auditType')` → target `audit_type` (STRING_255), tag `e2e`; expression preview (`PUT /admin/plugins/expression`) → no validation error; Save → 201 → `plugin.json`. Log it in `created/X19.jsonl`.
3. Validation negative: filter `event.type` (not boolean) → error message, nothing saved; restore the filter (no save needed).
4. Trigger (window active): Tenant Details of `{{TENANT}}` → "Save Tenant" **without any change** → `PUT /tenants/{{TENANT}}` 2xx (data-lake `AUDIT_LOG` with `auditType` UPDATE_TENANT). Never edit a field.
5. Tab "Data Table": within 3 min ≥ 1 row with `audit_type` = `UPDATE_TENANT` (`GET /admin/plugins/e2e-ops-p{{RUN_TAG}}/data…` → `data.json`); "Load more data into report table" works (PPCLOUD-12907). Tab "Data Graph" renders. Shots `05-table.png`, `05-graph.png`.
6. `GET /metadata/event-types` contains `AUDIT_LOG`.
7. Delete the plugin ("Delete", disabled only while locked) → `GET /admin/plugins/e2e-ops-p{{RUN_TAG}}` → 404.

Expect: plugin lifecycle; the audited save reaches the plugin table.

## Cleanup checklist

- Plugin deleted (404 saved); the tenant save changed nothing (compare `GET /tenants/{{TENANT}}` before / after: identical apart from audit fields).
