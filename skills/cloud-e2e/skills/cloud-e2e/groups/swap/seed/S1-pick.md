# S1 — pick people and days (group swap)

1. People of the claimed Gruppen with login, MITARBEITER_ID, Station and personnel category (read-only):
   ```
   scripts/sql.sh <env> "SELECT mp.ID||' '||lower(u.KUERZEL)||' node='||mk.KNOTEN_ID||' cat='||NVL(TO_CHAR(md.PERSONALKATEGORIE_ID),'?') FROM ECBERN.POLYUSER u JOIN ECBERN.MITARBEITER_POLYUSER mp ON mp.USER_ID=u.USER_ID LEFT JOIN ECBERN.MITARBEITER_KATEGORIEDETAIL mk ON mk.MITARBEITER_ID=mp.ID LEFT JOIN ECBERN.MITARBEITER_DETAIL md ON md.MITARBEITER_ID=mp.ID AND TRUNC(SYSDATE) BETWEEN md.GUELTIG_AB AND NVL(md.GUELTIG_BIS, DATE '9999-12-31') WHERE u.KUERZEL LIKE 'DMSEED-%' AND mp.ID IN (<claimed ids>) ORDER BY 3, 4;"
   ```
   The category column name is a guess (`PERSONALKATEGORIE_ID`): if the query fails, read the category per employee from the candidates step later (SWP-06 category filter) or from `MITARBEITER_KATEGORIEDETAIL` (category node) and note what you used. ASCII kürzel only.
