# Group swap — known deviations (KNOWN-FAIL signatures)

A mismatch that matches the **signature** of a row for that scenario is reported as KNOWN-FAIL: verdict `FAIL`, `findings_confirmed: ["<id>"]`, `notes` starting with `KNOWN-FAIL <id>`. A different signature, or a FAIL where the row says PASS, is new (`N-SWAP-<n>`). A listed deviation that does not show → PASS with "<id> not reproduced" in notes. Suspected-defect ids (SD-nn) refer to `synthesis/suspected-defects.md` of the cloud-E2E project and are given for the report only.
