## Conventions used by every scenario

- **Environment**: DeployMate env DM-X (`customer-roster`, master pin, on-prem 26.99.0 → every capability incl. `GET_ANNUAL_PLAN`, `GET_TEAM_ROSTER_FOR_WEEK`, `TIMESHEET`), tenant id `<env>`, shared with swap, booking, partner, hp. The embedding / Teams / device scenarios (HPN-22..27) are groups `shared` and `manual`. HPN-19 additionally needs the timesheet version gate (`data-plan.md` §1).
- **URLs (CT)**: myPP `https://ct-poma-webapp.dev.k8s.polypoint-dev.com/health-professional-app` (`{{APP}}`), webapp root `{{MYPP}}` = `https://ct-poma-webapp.dev.k8s.polypoint-dev.com`, poma-api `{{API}}` = `https://ct-poma-api.dev.k8s.polypoint-dev.com`, portal ops `https://ct-portal-webapp.dev.k8s.polypoint-dev.com`, PolyID ops `https://ct-polyid-login.dev.k8s.polypoint-dev.com/ops/`.
- **Harness**: `scripts/harness/app.mjs <env> <login> <script.mjs> <outdir> --app mypp` (desktop 1280 px), in-app mobile path `mypp-inapp.mjs` (390 px, cordova shim). **Routing rule** of `api.goto(path)`: a path starting with `/tabs/` is prefixed with `{{APP}}`, every other path with the webapp root — so non-tab app routes must be passed with the SPA prefix, e.g. `api.goto('/health-professional-app/flows/profile/notification-center', 'notifications')`, `api.goto('/health-professional-app/app/debug')` (`app.mjs` `api.goto`). The worker script may attach its own `page.on('request')` (headers), `page.route()` (fault injection), `ctx.grantPermissions(['clipboard-read','clipboard-write'], {origin: MYPP})` and `ctx.addInitScript()` — no harness change needed for those. Feature flags: `portal-ops.mjs <profile> "flag read|set|delete <env> <code> [value]" <outdir>` (the runner's portal-ops session) — only inside the group's window; wait for propagation (≈ 3 min portal cache + 60 s poma: `waitFlag()` of `e2e-lib.mjs`) and verify through a fresh myPP `config/features?appGroup=…` response. ### HPN-17 Timesheet gate and default (mock) path

> Data prerequisite: window W-X-TIMESHEET: `poma.flows.timesheet` ON for `<env>` (blocks the utr group's M family and every month-report reader while on); capability `TIMESHEET` in `capabilities.json`; `{{N4}}` (one employment, plannings in `M0`); `poma.mobileApp.debugPage` ON (baseline) — the "API-GW" toggle stays at its default (on = mock).
> Pre: fresh profile (no `TIMESHEET_MOCK` in storage).
> Steps: 1. Before the flag: `api.goto('/tabs/unified-time-recording/month-report?month={{M0}}')` → the month table (`pp-month-report-table`) is shown, no timesheet call. 2. After the flag (verify `timesheet: true` in a fresh features response): same route → `pp-timesheet` replaces the table; request `GET /api/mobile/timesheet/v1/reports?employment-id=<id>&month={{M0}}&mock=true`. 3. Response = the api-gw example document: record `envelope.month`, `envelope.employmentId`, `envelope.isPublished`, `envelope.formatted` (example: `2026-08`, `4711`, `true`, `false`, or a per-employment mock if api-gw has one). 4. UI: `.timesheet-info-banner` "Prüfen Sie Ihre erfassten Arbeitsstunden und Zulagen im <Monat> <Jahr>." for `{{M0}}`; one `pp-timesheet-account-section` per `accounts[]` entry (first expanded, titles = `sectionTitle`); `pp-benefits-overview-section`; day filter "Alle Tage"/"Nur mit Zulagen"; day rows = `days[]`. 5. Select "Nur mit Zulagen" → only days with allowance rows; if none → `.timesheet-no-allowance-days` with button → back to "Alle Tage". 6. Month selector → `{{M+1}}` → no banner (future); content shown because the example is published. 7. Switch the "API-GW" toggle twice (back to on) → requests carry `mock=false` then `mock=true`; the localStorage entry ending in `timesheet_mock` follows (`StorageKey.TIMESHEET_MOCK = 'timesheet_mock'`, `A/shared/storage-key.enum.ts:33`; written through `polypoint-angular-components` `StorageService` = ngx-webstorage `LocalStorageService`, default key prefix `ngx-webstorage|` — match by suffix).
> Expect: gate as listed; the cloud relays the api-gw document unchanged (byte-for-byte relay: response body = api-gw document, `TimesheetController.java` comment); UI counts = JSON counts.
> Oracle: requests/params; response envelope; DOM counts vs JSON arrays.
> Evidence: before/after screenshots, timesheet-\*.json, storage.json.
> Source: gaps G-01, G-04; MYPP-TS-01; PPCLOUD-14416…14419, -14472, -14612, APIGW-575.
