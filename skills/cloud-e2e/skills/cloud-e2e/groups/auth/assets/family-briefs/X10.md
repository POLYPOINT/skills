## AUT-10 — Tenant-wide TOTP: enforcement, running sessions, "2FA config missing" incident

1. `polyid-admin.mjs {{PIDOPS_PROFILE}} {{RUN_DIR}}/X10/AUT-10/p1 {{TENANT}} provider-2fa TOTP --window W-Y-TENANT2FA` → read back `capabilities.twoFactorType: TOTP` → `provider-totp.json`. Note T0.
2. T2FU fresh login (`polyid-flow.mjs {{TENANT}} "{{T2FU_LOGIN}}" <script> <out> --app mypp --fresh`): OTP enrolment page → `polyid.readOtpSecret()` → `polyid.submitOtp(polyid.totp(secret))` → `/tabs/`; `user-read "{{T2FU_LOGIN}}"` → `otp_verified: true` → `user-T2FU.json`.
3. OFFU: reopen myPP with the profile `X10-offu` (no login): home calls and `current-user/sync` answer 200, no 2FA page (shot `03-offu-still-in.png`).
4. OFFU: logout, fresh login (SEED, `--fresh`) → enrolment page appears (shot `04-offu-enrol.png`, masked); do **not** enrol; close.
5. **Restore** `provider-2fa DISABLED --window W-Y-TENANT2FA` → read back → `provider-disabled.json`. This step runs even when an earlier step failed.
6. TA (`app.mjs {{TENANT}} "{{TA_LOGIN}}" <script> <out> --app customer-portal`): `/portal/incidents` (capture the incidents API) → a new incident "2FA config missing", INFO, tenant `{{TENANT}}`, text "User <ops user> changed two factor authentication configuration, and now is missing for tenant {{TENANT}}" → `incidents.json`.
7. T2FU fresh login → no 2FA page (a Default override follows the tenant).
8. Cleanup: `reset-otp "{{T2FU_LOGIN}}"`, `reset-otp "{{OFFU_LOGIN}}"`.

Expect: as stated. The runner copies `provider-disabled.json` into the window doc as the restore proof.
