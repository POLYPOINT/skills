Source: `areas/hp-notif/data-plan.md` (A-hp-notif, 2026-10-23) with the S1 reconciliations: DM-X tenant only (VIEWER share; no SSH, no PEP, no box allowlist — the myPP web runs on the CT cloud, the seed password comes from DeployMate `test-data`); the UI flags are the steward baseline; HPN-05 / HPN-21 use the group's **own** swap N5 → N5c (no dependency on the swap or planner groups); timesheet HPN-17..20 is group `ts`; HPN-24 / 26 are `shared`, HPN-22 / 23 / 25 / 27 `manual`.

DM-X, master pin (on-prem 26.99.0 → `GET_ANNUAL_PLAN`, `GET_TEAM_ROSTER_FOR_WEEK`). DeployMate tenants register only POMA + PolyID: smartPEP pages (planning preferences / agreements, qualifications, additional balances on ≥ 25.4, SR v2) cannot work there (HPN-06 records it as HPN-K6).
