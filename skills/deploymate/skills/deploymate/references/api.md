# DeployMate REST API reference

Base URL `https://deploymate-api.dev.k8s.polypoint-dev.com/api/v1`. Verified against `cloud/deploy-mate` @ 8264e0f (image 1.37.0, 2026-10-13); sharing, allowlist and quota facts re-verified against 1.40.4 (daa461a, 2026-10-22). All routes except `/actuator/health` require `Authorization: Bearer <PolyId JWT>` from Keycloak realm `polypoint-polyid-realm` (`https://ct-keycloak.dev.k8s.polypoint-dev.com/auth/realms/polypoint-polyid-realm`). Roles in `realm_access.roles`: `ROLE_DEPLOY_MATE_USER` → authority `engineer` (create + manage own and shared envs), `ROLE_DEPLOY_MATE_ADMIN` → `admin` (read-only fleet, quota writes). Owner-only resources answer 404 to strangers (existence stays hidden). JSON everywhere; errors are `{"code": "<snake_case>", "message": "…"}`.

## Token

Public SPA client `deploy-mate-spa` (PKCE). Allowed grants: `authorization_code`, `refresh_token`. Refresh:

```bash
curl -s -X POST "$AUTHORITY/protocol/openid-connect/token" \
  -d grant_type=refresh_token -d client_id=deploy-mate-spa --data-urlencode "refresh_token=$RT" | jq -r .access_token
```

Access tokens live minutes; offline refresh tokens (scope `offline_access`, the SPA's "stay signed in") survive browser restarts. `scripts/dm-login-capture.mjs` stores them; `scripts/dm-api.sh token` refreshes and rotates.

### CreateEnvironmentRequest

| Field               | Type / default                                                                                                     | Rules                                                                                                                                               |
| ------------------- | ------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                | string, required                                                                                                   | `^[a-z][a-z0-9-]{0,14}$`, ≤15 (Oracle hostname); also tenant id, DNS label, email domain                                                            |
| `track`             | string, required                                                                                                   | from `GET /release-tracks` (`master`, `main-26`; main-23/24 hidden)                                                                                 |
| `version`           | string, required                                                                                                   | ADO stages: a hint only (`26.1.0`, `26.0.7` for master); rc/prod: must exist in `gs://polypoint-releases/<line>/` and be ≥ the image's baked schema |
| `stage`             | `CT`\|`REVIEW`\|`PREVIEW`, required                                                                                | which cloud the tenant is created on                                                                                                                |
| `onPremStage`       | `DEV`\|`RC`\|`PROD`\|`REVIEW`, null                                                                                | null → PROD if the track ships it, else first stage (master → DEV)                                                                                  |
| `gcpProject`        | string, null                                                                                                       | VM project; null → operator default (`GET /vm-projects`)                                                                                            |
| `machineSize`       | `SMALL`\|`DEFAULT`\|`LARGE`, DEFAULT                                                                               | n4d-standard ladder; CHF/day 3.50 / 8.50 / 18.00                                                                                                    |
| `p2Enabled`         | bool, true                                                                                                         | required true with `dbDump`                                                                                                                         |
| `solutions`         | map key→bool, {}                                                                                                   | per-env `solution_*` toggles, server-canonicalised (locked-on forced true)                                                                          |
| `seedConfig`        | `{preset, peopleCount 1..50 (40), includePalette true, includeLoginUsers false, includeRest false, randomSeed 42}` | null → catalog default; cloud-gated layers (login users, REST) forced off on non-cloud-capable tracks                                               |
| `licenseConfig`     | `{enabled true, apps{}, activeEmployees 500, namedUsers 500, customerName}`                                        | null → full bundle                                                                                                                                  |
| `dbDump`            | key, null                                                                                                          | from `GET /db-dumps`; ignores seed/licence; adds `LOADING_DB_DUMP`                                                                                  |
| `ipAllowlist`       | CIDR[] (bare IP ok), []                                                                                            | each validated; stored as sent: the API adds no office VPN range (only the SPA wizard pre-fills `10.42.0.0/16`); ≈ 10 entries fit (Cloud Armor)     |
| `sshPublicKeys`     | string[] ≤5, []                                                                                                    | OpenSSH lines for `pp-01`                                                                                                                           |
| `emailDomain`       | DNS name, null                                                                                                     | null → `<id>.ch`; becomes the portal domain mapping + PolyId email domain                                                                           |
| `ttlDays`           | int, null                                                                                                          | default 7; clamped to created+30 d                                                                                                                  |
| `timeRecordingMode` | `LEGACY`\|`UNIFIED`, UNIFIED                                                                                       | tenant toggles `poma.mobileApp.timeRecording` (always on) and `…unifiedTimeRecording`                                                               |
| `prSources`         | `[{repo: P2\|PP_SERVICES, prId}]`, []                                                                              | master only, ≤1 per repo, PR validated live (exists, active, targets master); mutually exclusive with a pin on the same repo                        |
| `masterBuildPins`   | `{P2\|PP_SERVICES: "<version>"}`, {}                                                                               | master only; version must exist in the feed (`GET /master-builds`); pp-services pins also need `bootstrap-app` at that version                      |
| `tailscale`         | `TailscaleRequest`, null                                                                                           | connection id or browser enrolment                                                                                                                  |
| `longLived`         | bool, false                                                                                                        | needs `ROLE_long_lived` (admins, allow-listed clients); never reaped                                                                                |
| `sourceRevisionId`  | uuid, null                                                                                                         | clone from a Materialized Environment revision (feature-flagged)                                                                                    |

### EnvironmentResponse

`id, ownerId, track, version, stage, onPremStage, machineSize, zone, machineType, gcpProject, p2Enabled, solutions, emailDomain, provisioningState, lastFailedState, lastErrorMessage, retryCount, nextAttemptAt, retryLimit, cancelRequested, ipAllowlist, sshPublicKeys, ttlExpiresAt, ttlReminderSentAt, scheduledDestroyAt, costToDateChf, instanceState (RUNNING|STOPPED|STARTING|STOPPING|null), autoStopEnabled, longLived, kind (STANDARD|TEMPLATE_BUILD|TEMPLATE_VALIDATION|CLONE), sourceRevisionId, seedConfig, lastSeededAt, licenseConfig, dbDump, timeRecordingMode, prSources[{repo, prId, title, sourceRefName, webUrl, buildRunId, buildWebUrl, artifactFeed, artifactVersion}], masterBuildPins, createdAt, updatedAt`. No IP field: derive the host from DNS (`<id>-host.deploymate.polypoint.dev`).

### ProvisioningState

`PENDING → [BUILDING_PR_ARTIFACTS] → PROVISIONING_VM → WAITING_FOR_SSH → RUNNING_HEALTH_CHECK → [LOADING_DB_DUMP] → CONFIGURING_CLOUD_TENANT → INSTALLING_NOMAD_CONSUL → INSTALLING_IDM → INSTALLING_SOLUTION → DONE`. Sink `ERROR`. Teardown `CANCEL_REQUESTED → CLEANING_UP → DESTROYED`. Excursions from DONE: `REAPPLYING_FIREWALL`, `RE_SEEDING`, `APPLYING_SSH_KEYS`. Clones: `RECONCILING`; builders: `SEALING`, `CAPTURING`. "In flight" (quota) = everything except DONE, ERROR, DESTROYED.

## Credentials (one-shot reveal pairs)

`POST /environments/{id}/credentials/{rdp|db|pep}/reveal` → 201 `{token, expiresAt}` (60 s, owner or operator). `POST …/consume` with `{"token": "…"}` → 200:

- rdp: `{username: "pp-01", password}`. 409 `rdp_not_ready` before DONE, 409 `rdp_password_not_provisioned`.
- db: `{username: "VINCULUM_FLEET[ECBERN]", proxyUser, targetSchema, password, host, port: 1521, service: "POLYP01", jdbcUrl}`. 409 `db_not_ready`, `db_password_not_provisioned`.
- pep: `{password, realm, username: null, note}` — only for `PRESERVE_IDENTITIES` dump envs (404 otherwise); every imported PEP user shares this password, `adminec` keeps the configurer superuser password. 409 `pep_not_ready`, `pep_password_not_provisioned`.

Spent, expired or mismatched token → 404 `not_found`. The token travels in the body on purpose (never in the URL).

## Error codes

| HTTP | code                                                                                                                                                                                                                                 | Meaning                                                                    |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------- |
| 400  | `validation`                                                                                                                                                                                                                         | bean validation, message lists `field: reason`                             |
| 400  | `invalid_track`, `invalid_release_version`, `invalid_pr_source`, `invalid_master_build_pin`, `invalid_db_dump`, `invalid_gcp_project`, `ttl_hard_cap`, `operator_cidr_not_single_host`, `quota_config_invalid`, `schedule_lead_time` | create/update rejected, message says why                                   |
| 403  | `long_lived_not_allowed`, `clone_not_allowed`                                                                                                                                                                                        | missing authority                                                          |
| 404  | `not_found`                                                                                                                                                                                                                          | unknown env, non-owner, spent reveal token                                 |
| 409  | `conflict`, `retry_not_allowed`, `reseed_not_allowed`, `ttl_extend_not_allowed`, `vm_action_not_allowed`, `*_not_ready`, `*_not_provisioned`                                                                                         | wrong state                                                                |
| 429  | `per_owner_cap` (Retry-After 60), `in_flight_cap` (Retry-After ≤300)                                                                                                                                                                 | quota                                                                      |
| 500  | —                                                                                                                                                                                                                                    | GCS/ADO unreachable during validation (never reported as a 400 on purpose) |
